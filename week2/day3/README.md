# AI Resume Matcher – Prompt Chaining

An AI-powered resume matching application built using Python and the Groq API. This project demonstrates **Prompt Chaining**, an AI engineering technique in which a complex task is divided into smaller steps, with the output of one prompt becoming the input to the next.

The application extracts skills from a candidate's resume and a job description, compares them, and generates a match score with a hiring suitability verdict.

## Concepts Learned

- **Prompt Chaining:** Breaking complex tasks into sequential LLM calls.
- **LLM Integration:** Connecting Python applications with Groq API.
- **System Prompts:** Defining the role, behaviour, and expected output of an LLM.
- **Prompt Engineering:** Designing specific instructions for reliable outputs.
- **Sequential Execution:** Passing the output of one LLM call into another.
- **Environment Variables:** Securely managing API keys using `.env`.
- **Modular Programming:** Separating individual AI tasks into reusable functions.

## Project Workflow

The application follows three sequential steps:

### Step 1: Resume Skill Extraction

- Takes the candidate's resume as input.
- Uses an LLM to extract technical skills.
- Returns only comma-separated skills.
- Avoids inventing skills that are not present in the resume.

### Step 2: Job Description Skill Extraction

- Takes the job description as input.
- Extracts the required technical skills.
- Returns a comma-separated list of required skills.

### Step 3: Candidate and Job Matching

- Takes the extracted candidate skills and job requirements.
- Compares both skill sets.
- Generates a match score between 1 and 100.
- Provides a short verdict on candidate suitability.

## Prompt Chaining Architecture

```text
             Resume + Job Description
                       |
                       |
             +---------+---------+
             |                   |
             v                   v
       STEP 1: Resume       STEP 2: JD
       Skill Extraction    Skill Extraction
             |                   |
             v                   v
       Candidate Skills     Required Skills
             |                   |
             +---------+---------+
                       |
                       v
             STEP 3: Skill Matching
                       |
                       v
               Final Match Score
                       |
                       v
                Hiring Verdict
```

## Example Input

**Job Description:**

```text
Backend Python Developer

Requirements:
- Strong Python
- FastAPI or Django
- PostgreSQL
- Docker
- AWS
- REST APIs
- 2+ years of experience
```

**Candidate Resume:**

```text
Name: Rahul Sharma

Experience:
3 years as a Software Developer.

Skills:
Python, FastAPI, MySQL, Docker,
REST APIs, Git

Projects:
Built a food delivery backend using
FastAPI and MySQL.

Deployed applications using Docker.
```

## Example Output

**Step 1 – Candidate Skills:**

```text
Python, FastAPI, MySQL, Docker, REST APIs, Git
```

**Step 2 – Required Job Skills:**

```text
Python, FastAPI, Django, PostgreSQL, Docker, AWS, REST APIs
```

**Step 3 – Candidate Matching:**

The LLM generates a match score between 1 and 100 and a short suitability verdict based on the candidate's skills and job requirements.

*Note: The actual score and verdict are generated by the LLM and may vary.*

## Project Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <project-folder>
```

### 2. Create a virtual environment

```bash
uv venv
```

### 3. Activate the environment (Windows)

```powershell
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
uv add groq python-dotenv
```

### 5. Configure environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
```

Never expose your API key or commit the `.env` file to GitHub.

### 6. Run the application

```bash
python main.py
```

## Key Takeaway

This project helped me understand how to build multi-step AI workflows using Prompt Chaining.

Instead of asking an LLM to perform an entire complex task in a single prompt, I divided the resume-matching process into three independent steps and connected them sequentially.

This approach makes AI applications more modular, easier to understand, test, and maintain.
