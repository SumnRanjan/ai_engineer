## How It Works

The application follows these steps:

1. Load environment variables from the `.env` file.
2. Retrieve the Groq API key securely.
3. Initialize the Groq client.
4. Select the LLM model.
5. Prepare a user message using the messages structure.
6. Send the request to the Groq API.
7. Receive the LLM response.
8. Extract and print the generated answer.

## Code Explanation

### 1. Import Libraries

```python
import os
from dotenv import load_dotenv
from groq import Groq
```

- `os`: Access environment variables.
- `load_dotenv`: Load environment variables from `.env`.
- `Groq`: Initialize the Groq API client.

### 2. Load API Key

```python
load_dotenv()

my_api_key = os.getenv("GROQ_API_KEY")

if not my_api_key:
    raise ValueError("API KEY NOT FOUND")
```

The API key is stored in the `.env` file instead of being hardcoded into the Python application.

### 3. Initialize Groq Client

```python
client = Groq(api_key=my_api_key)
```

Creates a client instance that allows the Python application to communicate with Groq's API.

### 4. Select the Model

```python
model = "openai/gpt-oss-120b"
```

Selects GPT-OSS 120B, an open-weight language model developed by OpenAI and hosted on Groq.

### 5. Prepare the Prompt

```python
role = "user"
prompt = "Do you know Virat Kohli?"

message = {
    "role": role,
    "content": prompt
}

messages = [message]
```

The messages parameter contains a list of conversation messages.

Each message contains:

- `role`: Identifies who is sending the message.
- `content`: Contains the actual text or prompt.

Common roles:

- `system`: Defines the assistant's behaviour.
- `user`: Contains the user's input.
- `assistant`: Contains the AI-generated response.

### 6. Send Request to LLM

```python
response = client.chat.completions.create(
    model=model,
    messages=messages
)
```

Sends the conversation to Groq's chat completion API and receives the generated response.

### 7. Extract AI Response

```python
answer = response.choices[0].message.content

print(answer)
```

The API returns a response object containing generated choices.

`response.choices[0].message.content` extracts the text generated by the model.

### 2. Create Virtual Environment




Never commit your actual `.env` file to GitHub.

```bash
python hello_llm.py
```
