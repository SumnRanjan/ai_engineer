## Implementation

### Python Code

```python
import os
from dotenv import load_dotenv
from groq import Groq

# Load environment variables
load_dotenv()

# Get API key
my_api_key = os.getenv("GROQ_API_KEY")

if not my_api_key:
    raise ValueError("API KEY NOT FOUND")

# Initialize Groq client
client = Groq(api_key=my_api_key)

# Model selection
model = "openai/gpt-oss-120b"

# Message role
role = "user"

# Different prompts
prompt1 = "Hi!"
prompt2 = "Explain time travel in detail but under 100 words"
prompt3 = "Write a 100 word essay on Machine learning"

prompts = [prompt1, prompt2, prompt3]

# Process prompts
for prompt in prompts:

    message = {
        "role": role,
        "content": prompt
    }

    messages = [message]

    response = client.chat.completions.create(
        model=model,
        messages=messages,
        max_tokens=500
    )

    # Token usage
    usage = response.usage

    print(
        f"Prompt: {prompt} --> "
        f"Your tokens: {usage.prompt_tokens} "
        f"Completion tokens: {usage.completion_tokens} "
        f"Total tokens: {usage.prompt_tokens + usage.completion_tokens} "
        f"Finish Reason: {response.choices[0].finish_reason}"
    )
```

## Understanding Token Usage

LLMs process text in smaller units called tokens.

The Groq API provides token usage information in the response.

| Parameter | Meaning |
|---|---|
| `prompt_tokens` | Tokens consumed by the input prompt |
| `completion_tokens` | Tokens generated by the model |
| `total_tokens` | Total input and output tokens |
| `finish_reason` | Reason why generation stopped |

### Token Calculation

```python
total_tokens = (
    usage.prompt_tokens +
    usage.completion_tokens
)
```

**Example:**

If the API reports:

- Input tokens: 15
- Output tokens: 80
- Total tokens: 95

Then:

`15 + 80 = 95 tokens`

Actual token consumption depends on the prompt and generated response.

## Understanding Chat Completions

The following code sends a request to the LLM:

```python
response = client.chat.completions.create(
    model=model,
    messages=messages,
    max_tokens=500
)
```

- `model`: Specifies which LLM to use.
- `messages`: Contains the conversation messages.
- `max_tokens`: Sets the maximum generation-token limit.
